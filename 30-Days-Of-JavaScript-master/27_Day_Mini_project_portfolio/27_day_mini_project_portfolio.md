<a id="练习"></a>
## 练习

<a id="练习1-级"></a>
### 练习：1 级

1. 使用 HTML、CSS 和 JavaScript 创建一个个人作品集页面。

   实现要求：

   - 页面应包含姓名、简介、技能、教学内容或项目展示等信息。
   - 使用 JavaScript 实现动态文字或内容切换效果。
   - 使用颜色、排版和动画增强页面表现力。
   - 页面在不同屏幕宽度下都应保持良好的可读性。
   - 作品集内容可以替换成你自己的真实信息。
