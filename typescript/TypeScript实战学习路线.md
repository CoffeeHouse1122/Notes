# TypeScript 项目实战知识点清单（不是学习计划）

> 目标：你可以把下面每个知识点直接映射到真实项目，而不是停留在语法记忆。

---

## 1) 基础类型与函数类型（必须扎实）

### 要掌握
- string / number / boolean / object / array / tuple
- 函数参数类型、返回值类型、可选参数、默认参数
- any / unknown / never / void 的边界

### 项目中怎么用
- 所有工具函数都写明确入参与返回值，避免隐式 any
- 接口原始返回先用 unknown 接收，再做类型缩小

### 常见坑
- 用 any 让错误延后到运行期
- 返回值不标注导致推断过宽

---

## 2) 对象建模：interface 与 type

### 要掌握
- interface 描述对象结构
- type 用于联合类型、交叉类型、别名组合
- 可选属性、只读属性、索引签名

### 项目中怎么用
- API 数据结构、组件 props、表单模型统一建模
- 活动配置 JSON 明确定义字段，防止字段名写错

### 常见坑
- 一个字段在多个地方重复手写，后续改字段漏改

---

## 3) 联合类型与类型缩小（业务状态核心）

### 要掌握
- 联合类型 A | B
- typeof / in / instanceof 缩小
- 可辨识联合（discriminated union）

### 项目中怎么用
- 请求状态统一为 loading | success | error
- 抽奖、报名、支付等流程状态用联合类型表达

### 常见坑
- 不做缩小就直接访问字段，导致编译报错或断言泛滥

---

## 4) 泛型（复用能力核心）

### 要掌握
- 泛型函数、泛型接口、泛型约束 T extends U
- 泛型默认值

### 项目中怎么用
- 通用请求函数 request<T>()
- 列表组件、表格组件、分页函数做类型复用

### 常见坑
- 泛型参数命名混乱
- 为了通过编译乱加 as

---

## 5) keyof / typeof / 索引访问类型

### 要掌握
- keyof T
- typeof value
- T[K]

### 项目中怎么用
- 根据配置键名安全取值
- 约束排序字段、筛选字段必须来自模型已有键

### 常见坑
- 把字符串当作任意 key 传入，丢失类型保护

---

## 6) 工具类型（高频）

### 必会
- Partial<T>
- Required<T>
- Pick<T, K>
- Omit<T, K>
- Record<K, V>

### 项目中怎么用
- 编辑表单：Partial
- 列表简版项：Pick
- 构造映射表：Record

### 常见坑
- 不理解工具类型的语义，直接复制粘贴造成类型变形

---

## 7) 条件类型与映射类型（进阶但实用）

### 要掌握
- T extends U ? X : Y
- 映射类型 [K in keyof T]
- infer 的基本用途

### 项目中怎么用
- 根据接口返回结构提取有效数据类型
- 自动生成只读版、可选版业务模型

### 常见坑
- 过度类型体操，阅读成本高于收益

---

## 8) tsconfig 关键配置（工程化落地）

### 必懂字段
- strict
- noImplicitAny
- strictNullChecks
- noUncheckedIndexedAccess
- module / target / lib
- baseUrl / paths

### 项目中怎么用
- 新项目默认 strict
- 老项目迁移时分阶段收紧，不要一步到位

### 常见坑
- 配置过松，TS 形同虚设

---

## 9) API 类型设计（你最该优先）

### 要掌握
- ApiResponse<T> 统一返回结构
- 分页类型 PageResult<T>
- 错误类型（网络错误/业务错误）

### 项目中怎么用
- 所有请求层函数返回 Promise<ApiResponse<T>>
- 页面层禁止直接消费 any

### 常见坑
- 后端字段变更后无编译提示，问题拖到线上

---

## 10) 组件与事件类型（前端高频）

### 要掌握
- props 类型
- emits/callback 参数类型
- DOM/Event 类型（输入、点击、提交）

### 项目中怎么用
- 表单组件、弹窗组件、上传组件先补类型
- 高复用组件优先保证类型正确

### 常见坑
- 事件对象使用 any，导致属性访问不安全

---

## 11) 声明文件与第三方库类型

### 要掌握
- d.ts 基本写法
- @types 包的使用

### 项目中怎么用
- 老库无类型时先补最小声明，保证项目可编译

### 常见坑
- 全局声明污染，影响全项目类型推断

---

## 12) JS -> TS 迁移知识点（实战必备）

### 要掌握
- allowJs / checkJs 过渡策略
- 迁移顺序：数据模型 -> 请求层 -> 组件 -> 页面
- 临时 any 管理（加 TODO 与清理截止时间）

### 项目中怎么用
- 先迁移独立模块（比如活动页配置、抽奖逻辑）
- 每次只改一条链路，避免大爆炸

### 常见坑
- 一次性全改导致回滚困难

---

## 13) 你可以立即执行的知识点顺序（项目应用优先）

按这个顺序啃，收益最高：
1. 函数类型 + 对象建模
2. 联合类型 + 类型缩小
3. 泛型 + ApiResponse<T>
4. 工具类型五件套
5. tsconfig 严格模式
6. 组件 props 与事件类型
7. 迁移策略与 d.ts
